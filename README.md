# My Programming Projects

A collection of my first programs in different languages, created while learning to code as an engineering student.

## Contents

| Folder | Language | Description |
|--------|----------|-------------|
| `C-programming/` | C | Basic C programs (`main.c`) |
| `HTML/` | HTML | A first web page (`index.html`) |
| `Java/` | Java | Java practice (`Main.java`) |
| `JavaScript/` | JavaScript | JavaScript practice (`app.js`) |
| `PHP/` | PHP | A first PHP script (`index.php`) |
| `Python/` | Python | Python programs, starting with `hello.py` |

## How to run

```bash
# C
gcc C-programming/main.c -o main && ./main

# Java
javac Java/Main.java && java -cp Java Main

# JavaScript (Node.js)
node JavaScript/app.js

# PHP
php PHP/index.php

# Python
python3 Python/hello.py
```

For the HTML page, open `HTML/index.html` in your browser.
